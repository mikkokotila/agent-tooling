# Copilot service availability and actual review requests

Copilot quota exhaustion, unavailability and review execution status have no authority over work, completion or merge. Every actual submitted Copilot comment or change request has the same evidenced handling and conclusion requirements as any other reviewer's, including outdated inline feedback and a request-changes review with an empty body. No further Copilot review or approval is needed after its actual requests have been handled.

The collector identifies GitHub's built-in `dynamic/agents/copilot-pull-request-reviewer` workflow using its REST API path, `dynamic` event and workflow ID. Its jobs inherit that provenance. Duplicate GitHub Actions check runs are correlated by their actual check-run IDs, application identity and workflow job inventory. A loose name match never exempts repository build/test workflows, statuses or unrelated checks. The two reserved service contexts do not require a missing Copilot execution to appear. All actual non-service checks remain judged.

Raw failed, pending or unknown service outcomes remain in the snapshot and in `nonblocking_service_checks` on both CI gates. A readiness gate passing means there is no blocking CI failure/pending result; it does not claim Copilot's failed execution passed. The raw service result is excluded from monitor wakeup identity and local-validation generation, so quota changes cannot replay unchanged real CI failures or cause redundant local tests. Actual comments still change those identities and remain fully enforced.

The new policy replaces the account-recovery/yield instruction in both client mirrors and the per-turn prompt. Legacy account-hold records remain historical evidence; a fresh full collection reclassifies their service outcomes and releases obsolete holds without touching their real review receipts or other unresolved evidence. No database reset or fabricated passing receipt is used. This does not change GitHub repository protection settings or grant an administrative merge bypass.
